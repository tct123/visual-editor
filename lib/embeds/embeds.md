# Embeds (WIP)
Embeds are widgets inserted in the editor that are represented in the delta doc. There are 2 kinds: Standard embeds and custom embeds (WIP).

## Standard embeds
The editor has 3 standard embeds:
- image
- video player
- youtube video player (mobile only)

To use each embed a link pointing to that resource is needed, excepting the youtube player where a link to the youtube video is enough. 

Visual Editor can display any custom component inside of the documents.
